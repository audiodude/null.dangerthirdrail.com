As fun as it is to start with samples, I've realized that a 20 second sample can only influence a song so far. I don't know if it's some cognitive distortion, but most of the time when I have a style and a melody in my head for some lyrics I wrote, and I put the style in, a very similar melody comes out. Though it might take a few tries actually.

Anyways, for this one, I followed what's becoming my standard method: Write a chorus and a verse, generate it, see if anything sticks in my mind and I want to continue, and then write the rest of the song.
